# Reporting a security concern

Email [arhythmetic.units@gmail.com](mailto:arhythmetic.units@gmail.com) with
the subject **Security report**. Please do not disclose vulnerabilities in
public issues or pull requests.

Include the affected product or service, version if applicable, a description
of the issue and its potential impact, and minimal steps to reproduce it.
Remove credentials, personal data, and unrelated confidential information.

If a repository provides its own security policy, follow its reporting
instructions. General product support is available through the
[support page](https://arhythmetic-units.com/support/).
