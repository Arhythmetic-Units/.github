# Arhythmetic Units on GitHub

[Arhythmetic Units](https://arhythmetic-units.com/) makes instruments and tools
for electronic music. This public repository hosts the company's GitHub
organization profile and shared community guidance.

Visit the [company website](https://arhythmetic-units.com/) for products,
downloads, manuals, and research, or see [support](SUPPORT.md) for help.

## Repository contents

- [Organization profile](profile/README.md): the introduction displayed on the
  organization's public GitHub overview.
- [Contributing](CONTRIBUTING.md): guidance for public contributions.
- [Support](SUPPORT.md): product help and bug-report details.
- [Security](SECURITY.md): how to report a security concern privately.
- [Agent instructions](AGENTS.md): publication boundaries for automated edits.

GitHub uses `profile/README.md` as the
[public organization profile](https://docs.github.com/en/organizations/collaborating-with-groups-in-organizations/customizing-your-organizations-profile).
`CONTRIBUTING.md`, `SUPPORT.md`, and `SECURITY.md` also serve as
[organization defaults](https://docs.github.com/en/communities/setting-up-your-project-for-healthy-contributions/creating-a-default-community-health-file)
for repositories that do not provide their own versions.

## Public content only

Keep this repository limited to public company copy, links to published
resources, and community guidance. Product descriptions and availability
should match the live website. The profile references the website's published
wordmarks directly; no design files or product assets are stored here.

Do not add proprietary source code, algorithms, internal documentation,
unannounced plans, credentials, customer information, private repository
references, or development artifacts. Do not copy another repository or its
history into this one.

The `.gitignore` permits only the files listed for this repository. Adding a
file requires an intentional update to that list. This helps prevent accidental
staging; it does not inspect file contents or protect files already tracked by
Git. Review every changed file and the full staged diff before committing.

Product licenses and terms are provided with the respective products and
repositories. This repository does not grant a license to those products or
the company's branding.
