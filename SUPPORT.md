# Support

For product questions, installation help, and bug reports, visit
[Arhythmetic Units support](https://arhythmetic-units.com/support/) or email
[arhythmetic.units@gmail.com](mailto:arhythmetic.units@gmail.com).

Include:

- Product name and version.
- Operating system and version.
- Plugin host and host version, if applicable.
- Steps to reproduce the problem and what you expected to happen.
- Relevant error messages, with personal or confidential information removed.

Find installation links and documentation on the
[downloads and manuals page](https://arhythmetic-units.com/downloads/).

Use email for reports containing private information. Do not post credentials,
license keys, customer details, or private project files in public issues.
Report security concerns privately by email as well.
