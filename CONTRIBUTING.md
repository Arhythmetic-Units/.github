# Contributing

Use the project's own contribution instructions when available. For general
questions, product help, or feedback, visit
[Arhythmetic Units support](https://arhythmetic-units.com/support/).

## Issues and changes

- Search existing issues before opening a new one.
- For a bug, include the product and version, operating system, host and host
  version if applicable, steps to reproduce, and expected and actual behavior.
- Keep proposed changes focused and explain how you verified them.
- Discuss substantial changes with the maintainer before starting work.
- Be respectful and keep feedback specific to the work.

Share only material you have permission to publish. Remove personal data,
credentials, private source code, and confidential information from reports,
logs, screenshots, and attachments. Report security concerns privately using
the project's security policy or email
[arhythmetic.units@gmail.com](mailto:arhythmetic.units@gmail.com).

## Changes to the company profile repository

The `.github` repository accepts public company copy, links to published
resources, and community guidance. Verify product claims and availability
against the [live website](https://arhythmetic-units.com/).

Link to published assets and resources rather than importing website or
product files. Keep proprietary code, internal documentation, private
repository references, and unannounced information out of changes and pull
request descriptions. Check links and review the complete diff before
submitting a correction.
